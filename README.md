## About this Project:
This project demonstrates how swerve drive works and is perfect for beginners getting into mechanical engineering to build. It has belts, pulleys, gears, bevels, which are all basic things a mechanical engineer should know how to use. I personally learned a lot from building this project and hopefully you will have a nice display piece and an understanding of the basic principles of power transfer by the end of this project. 

## Why I made this:
I made this project so others could show off their skills in engineering and also as a showcase to present in front of my whole school. 

## How this functions:

The project is made up of a combination of complex gear ratios, pulleys, and precision CAD parts which must be print at 0.2mm of extrusion with a 0.4mm nozzle. The tolerances of the project are incredibly precise and I strongly encourage you to appreciate the model in CAD and see the level of rigor needed to assemble it before starting to source parts and build it yourself.

## NOTE: THIS PROJECT IS IN ITS V1, IM EXPERIMENTING WITH NEW TYPES OF FILAMENT FOR THE BELTS AS USING 95A TPU IS TOO STIFF FOR THE SWERVE DRIVE TO FUNCTION CORRECTLY 
## THE TPU SECTION OF THE DOWNLOADABLE STEP OR STL FILE SECTION IS STRONGLY RECOMMENDED TO BE PRINTED IN 80a-90a TPU FILAMENT.  (Suggested Filament is below)
